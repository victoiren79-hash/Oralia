🌍 Globe Stories

What if the world wasn’t a feed… but a map of human stories?

🚀 Inspiration
Most platforms today show content as endless scrolling feeds.
But life doesn’t happen in a feed — it happens in places.
Globe Stories was built from a simple idea:
Every country holds stories worth discovering.
So instead of scrolling down, you explore outward — across the world.

🌐 What it does
Globe Stories turns the world into an interactive storytelling space:
🌍 Rotate and explore a 3D globe
🗺️ Click any country to unlock local stories
📖 Read real human experiences tied to geography
✍️ Add your own story to any country
Each country becomes a living archive of experiences.

💡 Problem
Today’s content platforms have a major limitation:
Stories are disconnected from real-world context
Cultural and geographic identity gets lost
Everything becomes a uniform feed
We lose the feeling of where things actually happen.

✨ Solution
Globe Stories reintroduces context.

Instead of:
“What is trending?”
It asks:
“Where is this happening?”

By anchoring content to geography, the platform creates:
Stronger cultural connection
Better exploration of global perspectives
A more meaningful way to discover stories

🧭 How it works
User opens the interactive globe
Selects a country
Views stories linked to that region
Submits their own story tied to that location
The globe evolves as more stories are added

🛠️ Built With
HTML5
CSS3
JavaScript (Vanilla)
Interactive globe rendering (library or custom logic)

No frameworks. Just web fundamentals.

📁 Project Structure
index.html      # Main UI structure  
style.css       # Styling and layout  
script.js       # Globe interaction + story logic  

🎯 Key Features
Fully interactive globe interface
Country-based story system
Add & view stories per location
Lightweight and fast (no frameworks)
Clean, intuitive UX focused on exploration

🌍 Impact
Globe Stories is not just a project — it’s a new way of thinking about content:
Stories regain geographic meaning
Users explore rather than consume passively
The world becomes a shared narrative space
It bridges the gap between digital content and real-world context.

🔮 Future Vision
If expanded, Globe Stories could become:
A global storytelling network
A cultural discovery platform
A tool for education and geography learning
A travel inspiration system
A map of human experiences over time

How to design around a single strong idea

The world is already full of stories.
We just needed a better way to find them.
