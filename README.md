# 🌍 Globe Stories

What if exploring the world felt like discovering human stories instead of scrolling a feed?

Globe Stories is an interactive web app built with HTML, CSS, and JavaScript where users explore a globe, click on countries, and read or add stories tied to those locations.

---

## 🚀 Problem

Most content today is:

- Endless scrolling feeds  
- Disconnected from real-world location  
- Lacking geographic and cultural context  

We consume content, but we don’t explore where it comes from.

---

## 💡 Solution

Globe Stories reconnects stories to geography.

Users can:

- Explore an interactive globe  
- Click on any country  
- Read stories from that location  
- Add their own stories  

Each country becomes a collection of human experiences.

---

## 🌐 How it works

- The globe is displayed in the browser  
- Each country is interactive  
- Clicking a country opens its story panel  
- Users can add new stories per country  
- Stories are stored and displayed by location  

---

## ✨ Features

- Interactive globe UI  
- Country-based story system  
- Add stories per country  
- Simple and clean interface  
- Built with vanilla JavaScript (no frameworks)
